# Home SOC Lab

## Overview
This project demonstrates a beginner cybersecurity and networking lab built using VirtualBox and Ubuntu Linux. The purpose of the lab was to practice Linux administration, packet analysis, and network troubleshooting fundamentals.

## Tools Used
- Ubuntu Linux
- VirtualBox
- Wireshark
- Nmap

## Skills Practiced
- Linux navigation
- Network troubleshooting
- Packet capture and analysis
- Basic network scanning
- Virtual machine setup

## Commands Used
- ping
- ifconfig
- netstat
- nmap

## Wireshark Analysis
Using Wireshark, I captured and analyzed:

- DNS traffic
- ICMP (ping) traffic
- TCP/IP communication

## Findings
Observed DNS requests and HTTPS traffic using Wireshark.
